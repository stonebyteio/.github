# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in any Stonebyte product or repository, please report it privately:

- **Email:** [support@stonebyte.io](mailto:support@stonebyte.io) with the subject line `Security`
- or use **Report a vulnerability** on the repository's **Security** tab (GitHub private vulnerability reporting), where enabled.

Please **do not** open a public issue for security problems.

Include what you can: the affected product and version, steps to reproduce, and the impact you observed.

## What to expect

- We acknowledge reports within **5 business days**.
- We keep you informed while we investigate and fix the issue.
- We credit reporters in the release notes, unless you prefer to stay anonymous.

## Supported versions

Security fixes are released for the latest published version of each product.
